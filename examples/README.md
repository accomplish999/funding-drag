# Examples

These files are inputs. They are not a live funding print.

`btc-long.json` is a long with two venues, fees, and a flat trailing window. `eats-target.json` is a rate high enough that funding spends a 1 percent target inside the hold. `--strict` on that file exits 3. The body is still printed.

The CLI text for both files is in [docs/EXAMPLES.md](../docs/EXAMPLES.md).
