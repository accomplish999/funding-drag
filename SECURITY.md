# Security

This program does not take an API key. It does open HTTPS requests to public funding endpoints, and only those. It does not store an account. Inputs you type stay in the process, except the rates the page requests from the venues you selected.

Do not paste a key, a signature, or an account identifier into an issue anyway. A bug report needs the inputs and the output, not your identity at a venue.

If you find a vulnerability, open a private security advisory on this repository. Do not file a public issue that includes a working exploit against a dependency, and do not include credentials of any kind.

A wrong funding sign can lead a person to hold the expensive side. Treat a formula bug as a real bug. Include the input, the output, and the number you believe the formula should produce.
